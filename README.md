<h1>Bank API</h1>

<p>
API REST sencilla que simula operaciones básicas de un banco.
Construida con <strong>Spring Boot</strong>, orientada a demostrar una arquitectura clara,
endpoints predecibles y buenas prácticas en servicios backend.
</p>

<hr/>

<h2>Características</h2>
<ul>
  <li>API RESTful</li>
  <li>Arquitectura por capas</li>
  <li>Separación entre dominio, aplicación e infraestructura</li>
  <li>Endpoint de salud para monitoreo</li>
  <li>Preparada para despliegue en la nube</li>
</ul>

<h2>Objetivo del proyecto</h2>
<p>
Este proyecto tiene como objetivo servir como base para una API bancaria,
enfocándose en simplicidad, claridad estructural y facilidad de extensión
para futuras funcionalidades como cuentas, transferencias y autenticación.
</p>
